# create-app-dock

Create a new AppDock micro-frontend workspace.

```bash
pnpm create app-dock my-app
```

The initializer also accepts the npm-style alias:

```bash
pnpm init app-dock my-app --template default
```

Use `--force` only when you explicitly want to replace a non-empty destination directory. The initializer creates files
only; it does not install dependencies automatically.
